# Claude Code

From the library root:

```sh
python3 scripts/install.py writing-assistant --target /path/to/project/.claude/skills
```

For user-wide installation use `--target "$HOME/.claude/skills"`.
Start a new session if needed and invoke `/writing-assistant` or request it by
name. Availability and invocation depend on your Claude Code version. These
instructions do not install skills into the Claude web application.
